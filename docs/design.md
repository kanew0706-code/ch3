## 1. 設計原則

1. **內容優先**：訊息文字最亮；邊框、時間、按鈕都退到灰色。
2. **用顏色認人**：同名的人只靠名字顏色分辨，所以名字顏色要鮮明，而且在深色底上清楚可讀。
3. **一個重點色**：紫色只用在「主要動作」和「跟自己有關的東西」，例如送出、進入、自己的訊息、自己按過的表情、目前所在的房間、未讀數字。
4. **狀態色固定意義**：黃色 = 提醒（展示模式、字數快滿、送太快、標亮）；紅色 = 問題或離開（斷線、超過字數、離開按鈕、隱藏這個人）；綠色 = 在線。
5. **圖示用線條 SVG，不用 emoji**。表情回應的 5 個 emoji（👍 ❤️ 😂 😮 😢）是內容，所以例外。
6. **手機上所有能點的東西至少 44×44px**。

## 3. 版面

### 3.1 斷點
| 寬度 | 版面 |
|---|---|
| ≥ 900px | 電腦版三欄 |
| < 900px | 手機版單欄；房間列表、線上名單收起來 |

### 3.2 電腦版
```
┌──────────┬─────────────────────────────────┬──────────┐
│ 房間列表 │ [展示模式橫幅]                   │ 線上名單 │
│ 232px    │ 頂端列 56px                      │ 236px    │
│          │ [連線中斷橫幅]                   │          │
│          │ 訊息列表（捲動，佔滿剩餘高度）   │          │
│          │ 輸入區                           │          │
└──────────┴─────────────────────────────────┴──────────┘
```
- 整個畫面高度 = 視窗高度（`100dvh`），只有訊息列表會捲動。
- 浮動通知：聊天區內右上角，距右邊 16px，在橫幅和頂端列下方。

### 3.3 手機版
```
┌─────────────────────────────┐
│ ☰•  房間名稱   🔗  🔔  離開  │ 頂端列 56px，按鈕 44×44
│        (● 👥 5 人在線)       │ 人數列，按鈕高 32px
│ 訊息列表                    │
│                             │
│ 輸入區（貼在鍵盤正上方）    │
└─────────────────────────────┘
```
- ☰ 的紅點：其他房間有未讀時出現，直徑 9px，外圍有一圈 2px 的背景色。
- 輸入區要隨鍵盤往上推，不能被擋住（`100dvh` 或 `visualViewport`）。
- 浮動通知：訊息區頂端，左右各 10px，滿版寬。

## 4. 畫面與元件規格

### 4.1 輸入代號畫面（`Entry.dc.html`）
- 背景 `--bg-2`；最上方可能有展示模式橫幅（置中）。
- 卡片：最寬 400px，`--bg-1`，圓角 16px，內距 32/28/24px，置中。
- 由上到下：
  1. logo：46×46 紫色圓角方塊（13px），內有對話框圖示
  2. 標題「匿名聊天室」（22px）
  3. 說明：「不用註冊，取個代號就能聊。訊息不會被保存，只看得到你進來之後的對話。」
  4. （從房間連結進來時）「你將進入：**週五讀書會**」：`--accent-soft` 底、`--accent-line` 框、紫色鎖頭
  5. 標籤「你的代號」，右邊「2 / 9」
  6. 輸入框：高 46px、`--bg-3`、圓角 10px、字 16px；聚焦時紫框加 3px 光圈
  7. 「進入聊天室」按鈕：高 46px、滿版寬、紫底
  8. 盾牌圖示＋「請勿傳送個人資料或機密，拿到連結的人都能進入房間。」（12.5px，`--text-3`）
- **錯誤狀態**：輸入框外框變成 `--danger`，下方出現 `--danger-text` 的「代號不能只有空白」（`role="alert"`），按鈕變成 disabled 色。
- 頁面打開時，游標自動停在輸入框，並全選已帶入的代號。

### 4.2 聊天主畫面：電腦版（`Main.dc.html`）

#### 左欄：房間列表（232px，`--bg-1`）
- 頂部：26px 紫色 logo + 「匿名聊天室」（15px 粗體）。
- 小標題「房間」。
- 房間項目（高約 36px，圓角 8px，圖示 15px）：
  - 大廳：井號圖示，**沒有 ×**。
  - 私人房間：鎖頭圖示；名稱太長時顯示 …
  - 目前房間：`--accent-soft` 底，`--text-1` 字；× 一直顯示（22px 方形，`--bg-4` 底）。
  - 其他私人房間：滑鼠移上去才出現 ×。
  - 有未讀：名稱變粗、變亮，右側紫色數字膠囊（高 20px，11px 粗體）。
- 「＋ 開新房間」：虛線框（`--line-dashed`），圓角 8px。
- 最下方：分隔線 + 30px 頭像 +「小明」+「這是你」。

#### 頂端列（高 56px）
- 左：鎖頭（或井號）+ 房間名稱（16px 粗體）+「私人房間」灰字（12px）。
- 右，依序：
  1. 「複製連結」外框按鈕（高 34px，連結圖示，**只有私人房間才有**）；按下後暫時變成打勾＋「已複製」2 秒
  2. 靜音圖示按鈕（34px）
  3. 「離開」文字按鈕（`--danger-text`）

#### 橫幅
| 橫幅 | 位置 | 樣式 |
|---|---|---|
| 展示模式（只在階段一） | 聊天區最上方，頂端列之上 | `--warn-bg` 底、`--warn-text` 字、警告三角形，13px |
| 連線中斷 | 頂端列正下方 | `--conn-bg` 底、`--conn-text` 字、旋轉圓圈，`role="alert"` |

#### 訊息
- 一列 = 左側 32px 頭像 + 12px 間距 + 內容欄；左右內距 20px，上下 6px。
- 內容欄：「名字　時間」→ 內容 → 表情列。
- **自己的訊息**：`--own-bg` 底 + 左側 3px `--own-bar` 細線 + 名字後面「（你）」（`--text-3`）。
- **連續發言**：同一個人、間隔不到 5 分鐘的連續訊息，省略頭像和名字，左邊留 32px 空白；滑鼠移上去時，在空白處顯示時間。
- **引用區塊**（放在名字上方，頭像往下對齊名字）：回覆箭頭 + 被引用者名字（他的顏色）+ 前 50 字（`--text-3`，單行 …）。整塊是可點的連結。
- **網址**：`--link` 顏色。
- **滑鼠移上去**：整列底色 `rgba(255,255,255,.03)`；右上角浮出操作列（`--bg-3`，圓角 10px）：「回覆」｜👍 ❤️ 😂 😮 😢（每顆 30px）。
- **表情列**：膠囊按鈕「👍 **3**」。自己按過的用 `--accent-soft` 底和 `--accent-line` 框；滑鼠移上去，上方出現黑色提示框：「小明（你）、阿傑、小美 按了 👍」。
- **名字選單**：點別人的名字出現（寬 180px）：上面是小頭像 + 名字，下面是禁止符號 +「隱藏這個人」（`--danger-text`）。點自己的名字沒有選單。

#### 系統灰字
置中 12px `--text-3`，左右各一條 1px 線：`──── 連線中斷期間的訊息無法顯示 ────`

#### 「有新訊息」
訊息列表底部中央的紫色膠囊（高 32px，向下箭頭 +「有新訊息」，粗體）。使用者往上捲、離底部超過一個畫面高時才出現。

#### 輸入區（左右 16px，底部 14px）
- **回覆中列**：接在輸入框正上方、同底色，上方圓角：回覆箭頭 +「回覆 **阿傑**：內容…」+ ×（取消回覆）。
- **輸入框**：`--bg-3`，圓角 12px（有回覆列時只有下方圓角）；聚焦時 `--accent-line` 外框。內容依序是文字框（自動長高，最多 6 行）→ 字數 → 送出按鈕（38px 紫色方形，圓角 10px，送出箭頭）。
- **字數**：

  | 字數 | 顯示 |
  |---|---|
  | 0～249 | 不顯示 |
  | 250～300 | `--warn-text`「287 / 300」 |
  | 301 以上 | `--danger-text` 粗體「312 / 300」，輸入框外框變成 `--danger`，送出按鈕變 disabled |

- **輸入框下方提示**（12px）：
  - 送太快：時鐘圖示 +「送太快了，請稍等」（`--warn-text`，`role="status"`），2 秒後消失。
  - 平常：「Enter 送出 · Shift+Enter 換行」（`--text-3`）。可以只在第一次使用時顯示。
- 送出按鈕不能按的情況：內容是空的、超過 300 字、連線中斷中。

#### 右欄：線上名單（236px，`--bg-1`）
- 小標題「線上 — 6 人」。
- 每列：28px 頭像 + 名字（他的顏色、粗體）。
- 自己排第一個，後面加「（你）」。
- 被隱藏的人：灰色頭像、名字加刪除線，右邊有「取消隱藏」小按鈕（高 26px，`--bg-3`）。

#### 浮動通知
- 卡片最少 250px 寬，`--bg-3`，圓角 10px：8px 圓點（進入 `--ok`、離開 `--text-3`）+「**阿凱** 進入了 週五讀書會」（名字用他的顏色，房間名 `--text-3`）+ ×。
- 從右邊滑入，4 秒淡出；最多同時 3 則，由上往下疊。
- 合併：「**3 人**進入了 大廳」。

### 4.3 其他狀態（`States.dc.html`）

## 6. 無障礙
- 只有圖示的按鈕都有 `aria-label`：「房間列表」「複製連結」「靜音／取消靜音」「離開這個房間」「取消回覆」「關閉通知」「送出」。
- 表情按鈕的 `aria-label`：按讚、愛心、大笑、驚訝、難過。
- 輸入框都有 `<label>`（可以視覺上隱藏）。
- 訊息列表、浮動通知區域設為 `aria-live="polite"`；連線中斷橫幅、代號錯誤設為 `role="alert"`。
- 操作列 `role="toolbar"`，名字選單、長按卡片 `role="menu"`，裡面的選項是 `role="menuitem"` 的 `<button>`。
- 用鍵盤也要能操作，聚焦時要有清楚的紫色外框。
- 對比：`--text-1`、`--text-2`、`--text-3` 在所有背景上都要至少 4.5:1。
